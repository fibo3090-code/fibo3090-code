Featured
P2PEM — secure-p2p-chat · Rust · Tauri · React
End-to-end encrypted peer-to-peer messenger with no account and no server holding your history.
X25519 forward secrecy, AES-256-GCM, short authentication strings against man-in-the-middle
attacks, and NAT hole punching with relay fallback. Desktop releases for Windows, macOS and Linux.

Transit Diagram Studio · TypeScript · React
Local-first editor that turns game map screenshots into printable, Beck-style transit diagrams.
Runs entirely in the browser: no account, no server, no watermark. Domain logic is covered by
121 checks plus visual regression tests.

HIVE · Rust · Axum · React · paused
Local-first multi-agent platform. A coordinator agent turns a brief into sprints and tasks, then
dispatches sub-agents that edit files, run shells and commit code inside a sandbox on your
machine. 11-crate Rust backend, five LLM providers, local Ollama fallback.
